# Notes API

A simple REST API for creating and managing notes.

## Technologies

- Node.js
- Express
- MySQL
- Swagger / OpenAPI

## Installation

```bash
npm install
```

Create a `.env` file with your database configuration:

```env
DB_HOST=your_host
DB_USER=your_user
DB_PASSWORD=your_password
DB_NAME=your_database
DB_PORT=3306
```

Start the server:

```bash
npm run dev
```

The API runs on:

```text
http://localhost:3060
```

## API Documentation

Swagger UI:

```text
http://localhost:3060/api-docs
```
